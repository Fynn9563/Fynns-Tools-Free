# Fynn's Tools Free

Free tools for the Unity Editor.

**Fynn's Tools Free Complete — Avatars** and **Fynn's Tools Free Complete — Worlds** install the tools compatible with their project type as individual VPM dependencies. Each tool is also available separately.

| Tool | What it does |
|---|---|
| [Animation Tools](AnimationHierarchyEditor/README.md) | Edit animation paths, replace motions, automatically repath clips and repair broken bindings. |
| [Asset Organizer](AssetOrganizer/README.md) | Organize assets and their dependencies into folders by asset type. |
| [Build Size Viewer](BuildSizeViewer/README.md) | View Unity build size reports to see which assets contribute to avatar and world build sizes. |
| [Camera Utility](CameraUtility/README.md) | Match the position, rotation and lens of scene cameras and the Scene view. |
| [ClientSim Storage Cleaner](ClientSimStorageCleaner/README.md) | Clear local ClientSim storage between play sessions in VRChat world projects. |
| [Clipping Tester](ClippingTester/README.md) | Preview avatar animations on a temporary copy to check clothing and accessories for clipping. |
| [Controller Cleaner](ControllerCleaner/README.md) | Find and remove unused embedded objects from Animator Controllers. |
| [Controllers+](ControllersPlus/README.md) | Edit Animator controllers, states, transitions, parameters and BlendTrees, with templates, searches, toggle creation and optional VRChat tools. |
| [Copy/Cut/Paste](CopyCutPaste/README.md) | Copy, cut and paste assets between folders in Unity's Project window. |
| [Dynamics+](DynamicsPlus/README.md) | Edit, organize, remove and preview VRChat PhysBones, colliders and Contacts. |
| [FaceEmo Patches](FaceEmoPatches/README.md) | Optional editor fixes for FaceEmo. |
| [GoGoLoco Pose Changer](GoGoLocoPoseChanger/README.md) | Customize GoGoLoco poses using an NDMF build plugin. |
| [Hierarchy+](HierarchyPlus/README.md) | Customize the Unity Hierarchy with component icons, labels, colors and virtual collection folders. |
| [MatCap Maker](MatCapMaker/README.md) | Create and customize MatCap textures with editable presets, surface patterns, reflections, lighting and live previews. |
| [No Auto Game](NoAutoGame/README.md) | Control whether Unity switches to the Game view when entering Play Mode. |
| [Package Importer](PackageImporter/README.md) | Queue and import Unity packages, review existing assets and skip unchanged packages. |
| [Quick Toggle](QuickToggle/README.md) | Create object, component and blendshape animations, with optional VRCFury or Modular Avatar toggle setup. |
| [Reset Humanoid](ResetHumanoidTPose/README.md) | Restore a humanoid avatar to its T-pose. |
| [Texture Tools](TextureTools/README.md) | Create text textures, generate normal maps, edit colors, pack and unpack channels, automatically pack textures and process textures in batches. |
| [Unity Pet Framework](UnityPetFramework/README.md) | Create, import and display animated desktop pets in the Unity Editor. |
| [VRCSDK+](VRCSDKPlus/README.md) | Enhanced VRChat expression menu and parameter editing, SDK panel layouts, Content Manager and scene capture tools, with optional SDK patches. |

---

## Animation Tools

Edit animation paths, replace motions, automatically repath clips and repair broken bindings.

Based on Unity-Animation-Hierarchy-Editor by Dreadrith. Toolkit modifications by Fynn9563.

---

## Asset Organizer

Organize assets and their dependencies into folders by asset type.

Based on AssetOrganizer by Dreadrith. Toolkit modifications by Fynn9563.

---

## Build Size Viewer

View Unity build size reports to see which assets contribute to avatar and world build sizes.

Based on VRChat Build Size Viewer by [MunifiSense](https://github.com/MunifiSense/VRChat-Build-Size-Viewer). Toolkit modifications by Fynn9563.

---

## Camera Utility

Match the position, rotation and lens of scene cameras and the Scene view.

Based on CameraUtility by Dreadrith. Toolkit modifications by Fynn9563.

---

## ClientSim Storage Cleaner

Automatically clear local ClientSim player data and player objects after Play Mode in VRChat world projects, with an option to clear them manually.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Clipping Tester

Preview avatar animations on a temporary copy to check clothing and accessories for clipping.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Controller Cleaner

Find and remove unused embedded objects from Animator Controllers.

Based on ControllerCleaner by Dreadrith. Toolkit modifications by Fynn9563.

---

## Controllers+

Edit Animator controller layers, states, transitions, parameters and BlendTrees. Includes controller templates, fuzzy motion search, coloured parameter types, notes, ordering and usage/conflict indicators, transition labels and colours, animation searches, BlendTree copy/paste, reparenting, smoothing and group toggle creation, constant parameter animations, unused-blendshape searches, and graph and Inspector shortcuts. Optional VRChat features include expression parameter actions, avatar dynamics indicators and behaviour editing.

Based on Controller Editor by Dreadrith. Toolkit modifications by Fynn9563.

---

## Copy/Cut/Paste

Copy, cut and paste assets between folders in Unity's Project window.

Based on CopyCutPaste by Dreadrith. Toolkit modifications by Fynn9563.

---

## Dynamics+

Edit, organize, remove and preview VRChat PhysBones, colliders and Contacts.

Inspired by Avatar Dynamics Overhaul. Independently developed by Fynn9563.

---

## FaceEmo Patches

Optional FaceEmo fixes for transparent expression menu thumbnails and a blendshape picker that fits its contents.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## GoGoLoco Pose Changer

Replace GoGoLoco stand, crouch, prone, fall and AFK poses with your own animations during avatar builds. Supports a single AFK loop or separate start, loop and end animations.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Hierarchy+

Customize the Unity Hierarchy with component icons, labels, colors and virtual collection folders.

Based on HierarchyPlus by Dreadrith. Toolkit modifications by Fynn9563.

---

## MatCap Maker

Create and customize MatCap textures with editable presets, surface patterns, reflections, lighting and live previews.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## No Auto Game

Control whether Unity switches to the Game view when entering Play Mode.

Based on NoAutoGame by Dreadrith. Toolkit modifications by Fynn9563.

---

## Package Importer

Queue and import Unity packages, review existing assets and skip unchanged packages.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Quick Toggle

Create object, component and blendshape animations, with optional VRCFury or Modular Avatar toggle setup.

Based on QuickToggle by Dreadrith. Toolkit modifications by Fynn9563.

---

## Reset Humanoid

Restore a humanoid avatar to its T-pose.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Texture Tools

Create text textures, generate normal maps, edit colors, pack and unpack channels, automatically pack textures and process textures in batches.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## Unity Pet Framework

Display animated pets over the Unity Editor, create pets from sprite sheets with grid or automatic slicing, and import or share pets as .fynnpet files. Includes pet previews, animation editing, interactions and behaviour settings.

Created by [Fynn9563](https://github.com/Fynn9563).

---

## VRCSDK+

Enhanced VRChat expression menu and parameter editing, SDK panel layouts, Content Manager and scene capture tools, with optional SDK patches.

Based on VRCSDKPlus by Dreadrith. Toolkit modifications by Fynn9563.
