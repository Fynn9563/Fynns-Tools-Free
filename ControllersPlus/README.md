# Controllers+

Edit Animator controller layers, states, transitions, parameters and BlendTrees. Includes controller templates, fuzzy motion search, coloured parameter types, notes, ordering and usage/conflict indicators, transition labels and colours, animation searches, BlendTree copy/paste, reparenting, smoothing and group toggle creation, constant parameter animations, unused-blendshape searches, and graph and Inspector shortcuts. Optional VRChat features include expression parameter actions, avatar dynamics indicators and behaviour editing.

Based on Controller Editor by Dreadrith. Toolkit modifications by Fynn9563.
